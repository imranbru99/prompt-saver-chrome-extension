# PromptVault — AI Prompt Saver

**PromptVault** (Prompt Saver) is a complete Manifest V3 Chrome extension to **save, search, tag, and one-click inject** prompts into Gemini, ChatGPT, Claude, and other AI editors — privately on your device.

## Features

- One-click inject into page editors (contenteditable + textareas)
- Full CRUD for prompts
- Live search + comma-separated tags
- Premium emerald popup UI
- Private `chrome.storage.local` — no cloud required
- Marketing / product website included

---

## Install (Developer Mode)

```bash
git clone https://github.com/imranbru99/prompt-saver-chrome-extension.git
cd prompt-saver-chrome-extension
```

1. Open `chrome://extensions/`
2. Enable **Developer mode**
3. **Load unpacked** → select this folder
4. Pin **PromptVault**

---

## How to use

1. Click **+ New** → title, tags, prompt → **Save**
2. Open Gemini / ChatGPT / Claude
3. Click a prompt in the list to inject
4. Use search to filter quickly
